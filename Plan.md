# 📖 Overview

Mission 36 is a premium-looking static website documenting my 36-day journey from **August 3** to **September 7**.

Unlike LifeOS, Mission 36 is **not a productivity app**.

It is a visual roadmap that presents my goals, milestones, daily routine, weekly targets, certification preparation, internship journey, fitness transformation, and career progress in a clean and engaging format.

The website should feel like a modern product landing page instead of a traditional blog or documentation page.

---

- Present my August–September execution roadmap
- Document my AI-200 certification preparation
